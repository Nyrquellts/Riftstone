Skins

            
A skin is a new look for one enemy family. Placements wear it by number (the World tab's Skin field, or riftstone encounter --skin N); every other enemy of that kind stays as it is. Needs the enemy_skins plugin. How it looks in game: UNKNOWN until you try it.

          
Open this tab to list your skins.

        

      

    


    

      

        

        

          

          

        

      

      

      

        

          
Loader

          
The Riftstone loader serves your mods' archives from riftstone\overlay, so the game's own files are never overwritten, loads the plugins, and writes a report if the game crashes. An existing dinput8.dll (e.g. DDDA Tweak) keeps working, chained.

          

        

        

          
Back to vanilla

          
Puts every archive Riftstone changed back to the original, verified byte for byte. Your mod projects are untouched.

          

        

        

          
Reports

          
Written by the loader when the game crashes, stops with a fatal error or stops drawing frames: what went wrong, the engine objects involved, memory headroom, and the mods and files it touched. Click one for the explanation.

          

          

        

      

    


    

      

        

          

            
            
            
            
            
          

          

            
            
          

        


        

          

            
What Riftstone isリフトストーンとは

            
Riftstone is a fan-made modding suite for Dragon's Dogma: Dark Arisen and Dragon's Dogma Online. It reads the games' own files and lets you change them — enemies, spawns, skins, items, text, textures and more — then rebuilds them byte for byte, so nothing else in a file changes. Every format is checked against every matching file in the game.

            
The Riftstone loader runs your mods without overwriting the game's files, loads plugins (more enemies at once, less pop-in, enemy skins, save copies) and explains any crash. Press F10 in game for the diagnostics panel.

            
リフトストーンは『ドラゴンズドグマ:ダークアリズン』と『ドラゴンズドグマ オンライン』のためのファン製 MOD ツールです。ゲーム自身のファイルを読み込み、敵・出現・スキン・アイテム・テキスト・テクスチャなどを編集し、バイト単位でそのまま組み直します。編集した箇所以外は一切変わりません。

            
リフトストーンのローダーはゲーム本体のファイルを上書きせずに MOD を読み込み、プラグイン（同時に出現する敵の増加、ポップインの軽減、敵スキン、セーブのコピー）を読み込み、クラッシュの原因を説明します。ゲーム中に F10 で診断パネルを表示します。

          

        


        

          

            
Getting started使い方

            
    
              
  1. Diagnostics: install the loader (Dark Arisen). Riftstone checks your game build first.
    2. 
              
  2. Mods: switch plugins and mods on or off, change their settings, then Install.
    3. 
              
  3. Assets: search any resource (try goblin, em0100, status), add it to a mod and edit it; or port it to the other game.
    4. 
              
  4. World: pick a stage, click the map, and add an encounter (N of an enemy) the way the game builds its own hordes.
    5. 
              
  5. Launch from Home. Restore original files on Diagnostics puts everything back, verified byte for byte.
    6. 
            

            
    
              
  1. Diagnostics：ローダーをインストールします（ダークアリズン）。最初にゲームのビルドを確認します。
    2. 
              
  2. Mods：プラグインと MOD のオン・オフや設定を変更し、Install します。
    3. 
              
  3. Assets：任意のリソースを検索し（goblin、em0100、status など）、MOD に追加して編集するか、もう一方のゲームへ移します。
    4. 
              
  4. World：ステージを選んでマップをクリックし、ゲーム本来の群れと同じ仕組みで遭遇（敵 N 体）を追加します。
    5. 
              
  5. Home から起動します。Diagnostics の Restore original files ですべてを元に戻し、バイト単位で検証します。
    6. 
            

          

        


        

          

            
What you can edit編集できるもの

            
    
              
  • Textures — .tex ↔ .dds / .png, edit in any image tool; Frost, Lava, Abyssal and Weathered presets.
    • 
              
  • Enemy & character stats — .prp: attack, defence, magick, resistances, HP and size.
    • 
              
  • Spawns & enemy groups — every field of every placement, decoded with the game's own grammar; hordes and spawn caps.
    • 
              
  • World — every stage, its groups and every placement on one map; encounters as new groups.
    • 
              
  • Skins — chosen chimeras wear another look, such as Online's White and Shadow Chimeras.
    • 
              
  • Between the games — textures, text, models with their materials, motions and collision port from one game to the other.
    • 
              
  • Items, text, materials, collision, AI and more — each rebuilds byte for byte.
    • 
            

            
    
              
  • テクスチャ — .tex ↔ .dds / .png。任意の画像ツールで編集。フロスト・溶岩・深淵・風化のプリセット。
    • 
              
  • 敵・キャラクターのステータス — .prp：攻撃・防御・魔法・耐性・HP・大きさ。
    • 
              
  • 出現と敵グループ — 全配置の全フィールドをゲーム自身の形式で解読。群れと出現数の上限。
    • 
              
  • ワールド — 全ステージのグループと配置を1枚のマップで表示。新しいグループとして遭遇を追加。
    • 
              
  • スキン — 選んだキメラに別の外見を。オンラインのホワイト・シャドウキメラなど。
    • 
              
  • ゲーム間の移植 — テクスチャ・テキスト・マテリアル付きモデル・モーション・コリジョンを一方のゲームからもう一方へ。
    • 
              
  • アイテム・テキスト・マテリアル・コリジョン・AIなど — すべてバイト単位で組み直します。
    •
